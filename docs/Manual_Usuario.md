# Manual de usuario — SysTrack (versión inicial)

## Acceso
Abrir `http://localhost:3000`, ingresar correo y contraseña asignados. La cuenta demo inicial es `admin@systrack.local` / `Admin123!`; cambiarla antes de cualquier uso real.

## Resumen
La pantalla muestra conteos de activos, activos operativos, incidentes abiertos y mantenimientos pendientes.

## Activos
Entrar a Activos y seleccionar Nuevo activo. Completar código, nombre, categoría y los datos disponibles. El código debe ser único. Revisar el estado y guardar.

## Incidentes
Entrar a Incidentes y seleccionar Nuevo incidente. Registrar título, descripción, categoría, impacto, urgencia y activo asociado si corresponde. El sistema asigna prioridad inicial. Personal técnico autorizado puede avanzar el estado y registrar la solución.

## Mantenimientos
Entrar a Mantenimientos, seleccionar Programar, elegir activo, tipo preventivo/correctivo, fecha y descripción. Al ejecutar la actividad, el técnico utiliza Completar y describe el trabajo realizado.

## Cierre de sesión
Seleccionar Cerrar sesión al terminar. No compartir credenciales.

## Consideraciones
La interfaz es un prototipo académico. Algunas funciones avanzadas (filtros, historial completo por activo, exportación y administración integral de usuarios) están fuera de esta versión inicial.
